## 2. Информация об ОС

- OSVersion: Microsoft Windows NT 10.0.19045.0
- 64-битная ОС: True

**Вывод:** Совпадает с «Параметрами Windows».

## 3. Логические процессоры

- Результат программы: 3
- Диспетчер задач: 3
- Совпадают: да

**Вывод:** Environment.ProcessorCount показывает логические ядра. 

## 4. Память процесса

- WorkingSet: 19 МБ
- Диспетчер задач: ~19–20 МБ

**Вывод:** WorkingSet — это сколько памяти реально использует процесс прямо сейчас.


## Контрольные вопросы (коротко)

1. **Почему программа знает имя ПК?**  
   Берёт из ОС через Environment.MachineName.

2. **Роль ОС при запросе сведений?**  
   ОС — посредник между программой и железом.

3. **Что значит «64-битная ОС»?**  
   Может использовать больше 4 ГБ памяти и запускать разные приложения.

4. **Что показывает Environment.ProcessorCount?**  
   Логические процессоры (потоки), не обязательно равно числу физических ядер.

5. **Чем WorkingSet отличается от всей ОЗУ?**  
   WorkingSet — только память для этого процесса, ОЗУ — вся память ПК.

6. **Почему результаты разные на разных ПК?**  
   Потому что у всех разное железо и настройки ОС.


## Итоговый вывод

Программа не хранит данные о ПК а спрашивает у ОС. Поэтому на разных компьютерах результаты разные — они показывают реальную конфигурацию. Код один а значения зависят от среды.
